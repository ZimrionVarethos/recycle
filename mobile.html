            METHOD • ARSITEKTUR MACHINE LEARNING
          
          

            Alur Kerja CNN, Transfer Learning & Integrasi Flutter-Python
          

          

            Pendekatan *Transfer Learning* memanfaatkan bobot *Convolutional Neural Network* yang telah dilatih pada jutaan citra ImageNet, kemudian menyesuaikan lapisan klasifikasi akhir (*Dense Softmax Head*) khusus untuk mengenali tekstur, transparansi, dan bentuk 7 jenis sampah plastik.
          

        


        
        

          

            

              
                TAHAP 01 • FLUTTER CLIENT
              
              
Akuisisi & Pra-pemrosesan Citra

              

                Modul `camera` atau `image_picker` pada Flutter menangkap foto sampah plastik, melakukan pemotongan tengah (*center crop*), dan mengirim *multipart image* ke *endpoint* Python.
              

            

            

              Resolusi Input: 224 x 224 x 3 RGB
            

          


          

            

              
                TAHAP 02 • CNN BACKBONE
              
              
Ekstraksi Fitur Transfer Learning

              

                Lapisan konvolusi dari arsitektur *pre-trained* (MobileNetV2, EfficientNet-B0, atau ResNet-50) mengekstrak peta fitur tepi, kilap permukaan, dan lipatan botol.
              

            

            

              Feature Map: 7 x 7 x 1280
            

          


          

            

              
                TAHAP 03 • CLASSIFIER HEAD
              
              
Pooling, Dropout & Fine-Tuning

              

                Vektor fitur diringkas melalui `GlobalAveragePooling2D`, diberi regularisasi `Dropout(0.3)` untuk mencegah *overfitting*, dan diteruskan ke lapisan `Dense(256, ReLU)`.
              

            

            

              Optimizer: Adam (lr=1e-4)
            

          


          

            

              
                TAHAP 04 • SOFTMAX & API
              
              
Klasifikasi 7 Kelas & Respons JSON

              

                Lapisan akhir `Dense(7, Softmax)` menghasilkan persentase keyakinan untuk 7 kelas resin dan mengirimkannya kembali ke antarmuka Flutter secara *real-time*.
              

            

            

              Output: JSON 7-Class Vector
